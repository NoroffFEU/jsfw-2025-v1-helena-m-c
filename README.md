# Little Shop

Little Shop is an ecommerce application developed as part of the JavaScript Frameworks course at Noroff.

The project was built using Next.js, React, TypeScript and the Noroff Online Shop API. The goal was to create a complete shopping experience where users can browse products, search for items, view product details and complete a simulated checkout flow.

For Portfolio 2, I revisited the project and focused on improving both the visual presentation and the overall shopping experience.

## Project Overview

Little Shop is a fully responsive ecommerce application that retrieves product data from the Noroff Online Shop API.

The application allows users to browse products, search and sort listings, view individual product pages and manage a shopping cart throughout the purchasing journey.

The project was built with a strong focus on usability, responsiveness and creating a shopping experience that feels familiar and intuitive.

---

## Key Features

### Product Browsing

Users can:

* Browse products from the API
* Search products by name
* Sort products using multiple criteria
* View product information and pricing

### Product Details

Each product page displays:

* Product images
* Description
* Pricing information
* Discount information when available
* Customer ratings
* Add-to-cart functionality

### Shopping Cart

Users can:

* Add products to the cart
* Remove products from the cart
* Adjust quantities
* View cart totals

### Checkout Flow

Users can:

* Complete a simulated checkout process
* Receive confirmation after purchase
* Clear the cart after checkout

### Contact Page

The application includes a contact form with client-side validation.

Improvements included:

The goal was to make the project feel more like a complete ecommerce product and less like a course assignment.

## API

The application uses the Noroff Online Shop API to retrieve product data.

Products, product details and search functionality are all powered through live API requests.

API Base URL:

```txt
https://v2.api.noroff.dev
```

## Getting Started

### Clone the repository

```bash
git clone https://github.com/NoroffFEU/jsfw-2025-v1-helena-m-c.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
